In short

What is Trainer OS? Trainer OS is an offline client management app for personal trainers and online coaches. It stores client profiles, builds programs from 60+ exercises, logs workouts with last session's weights pre-filled, detects personal records automatically and tracks session packages and payments. It runs from one HTML file in the browser on a computer or Android phone, with a one-time payment and no subscription.

What you get

Everything inside Trainer OS

  • Client profiles with goals and injury notes
  • Program builder with 60+ exercises
  • Three starter programs to copy and adapt
  • Workout logger that pre-fills last weights
  • Automatic personal record detection
  • Body weight and strength progress charts
  • Session packages, payments and renewal alerts
  • Branded PDF training plans for clients

How it works

Made for real days, not demos.

Trainer OS keeps every client's goals, injuries, programs, sessions and progress in one place. On session day, press Start and the workout loads from the client's program with last time's weights already filled in.

Log weight and reps, press Finish, and new personal records are detected automatically. Sell session packages, see how many sessions each client has left, and get a reminder when it's time to offer a renewal.

Questions

About Trainer OS

Is Trainer OS a subscription?

No. Trainer OS is a one-time purchase. You download it once from the KREXZA store on Whop and keep using it.

Does Trainer OS need internet?

No. It runs from a single HTML file in your browser and saves data on your own device, so it works offline.

Can I use Trainer OS on iPhone?

Trainer OS needs a computer (Windows, Mac or Chromebook) or an Android phone with Chrome. It is not designed for iPhone.
